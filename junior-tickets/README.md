# Tiketi za junior developere — beauty-health.rs

Ovaj folder sadrži **tikete izvedene iz** `SPECIFIKACIJA_ZAHTEVA.md`, grupisane po **sprintovima**.

## Kako koristiti

- Svaki tiket je Markdown fajl sa rednim brojem i kratkim opisom u imenu.
- Unutra: cilj, opseg, kriterijumi prihvatanja, napomene za juniore, referenca na sekciju specifikacije.
- Redosled unutar sprinta odgovara preporučenom redosledu rada (gde zavisi od prethodnih tiketa).
